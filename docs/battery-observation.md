# 电芯一致性与放电能量参考

v0.7.0 增加电芯压差参考提示和逐次估算放电量。两项都用于观察数据与变化，不给出电池容量、SOH 百分比、剩余续航或电芯故障诊断，也不参与 NAS 的关机保护。

v0.11.0 另提供[相对容量参考](battery-capacity.md)：把当前校准阶段的首个合格区间固定为 100%，之后比较同区间、相近负载的观测变化。它使用独立记录，不把这里的历史会话总量反推成出厂健康度。

## 压差参考提示

压差按四节电芯读数中的最高值减最低值计算，单位为 mV。下列区间是本项目的提示规则，**不是绿联发布的健康标准，也没有经过 US3000 多机型仪器验证**。

| 持续压差 | 参考提示 | 建议 |
| --- | --- | --- |
| 小于 20 mV | 一致性较好 | 正常观察 |
| 20 至小于 50 mV | 存在轻微差异 | 留意长期变化 |
| 50 至小于 100 mV | 压差偏大 | 下次正常充电结束、稳定待机后复查 |
| 不小于 100 mV | 建议检查 | 稳定待机仍持续出现，或反复加重时联系售后 |

面板后台每次收到新的有效采样后推进观察，网页是否打开不会改变判断。设备必须连续处于外部供电、未充电的 `online` 状态至少 **30 分钟**，且当前区间持续至少 **2 分钟**，才显示确认后的参考等级。区间变化时重新确认，短暂尖峰仍会进入峰值记录，但不立即变成新的等级。

充电或电池供电期间显示当前压差与工况，不套用待机等级。数据失鲜、未知模式、无效电芯读数、倒序时间、相邻样本超过 5 秒、设备、采集来源或解码版本变化都会中断连续观察；面板服务重启后重新开始计时。重复读取同一时间戳不增加样本或观察时长。查看页面和后台观察之间尚有新样本未处理时，页面暂时显示观察中，不借用上一组数据的等级。

近期峰值与最常单独偏低的电芯，只统计**本次连续待机中的最近 30 分钟**，不是全历史结论。多个电芯并列最低时，不把该样本计为某一节单独偏低；计数并列时不指定某一节。7 天和 30 天按钮跳转到已有压差趋势，仍只显示实际已记录的历史。

电压显示位数不代表通道之间的测量准确度。电量位置、充放电电流、内阻和测量偏差都可能影响压差。TI 的[电芯均衡资料](https://www.ti.com/download/trng/docs/seminar/Topic%202%20-%20Battery%20Cell%20Balancing%20-%20What%20to%20Balance%20and%20How.pdf)说明了电量与负载对电芯电压差的影响；它支持这些判断边界，并不为上面的 US3000 提示区间背书。

## 本次估算放电量

新记录的能量计算使用：

```text
P = 电池侧放电功率候选 × 当前有效 battery_gain
每个有效区间的能量 Wh = (P前 + P后) / 2 × (时间后 − 时间前) / 3600
本次估算放电量 = 各有效区间能量之和
```

使用未经过显示平滑的采样估算值，保留完整精度计算；网页按适合阅读的位数显示。交流助手校准 `base_gain` 和 `charge_gain`，不会自动补上电池倍率。`none`、未配置 `battery_gain` 或配置依据不完整的区间不参与积分；整条记录没有有效功率区间时显示暂无估算，不当成 0 Wh，也不自动套入开发样机系数。已有有效区间仍保留估算量，缺失区间被排除并标注覆盖不足。

仅连接新鲜、时间递增、相邻不超过 **5 秒**、设备/来源/模型与校准依据一致的两次 `battery` 采样。无效读数及缺口不插值补全，切入电池和恢复外电的边界不补算。设备、来源或有效功率依据改变时，原记录会分段，避免把不同依据混为同一次估算。

每条记录另行显示：

- **估算放电量**：只覆盖实际有效区间，不是整台 UPS 的总容量。
- **有效覆盖时长与比例**：分母是首末电池采样之间的时间，分子是实际参与积分的区间时长；不包含恢复外电前无法观测的边界。只有一个电池采样时，没有可计算的时间区间。
- **功率依据及缺口原因**：说明使用标称容量假设还是自定义倍率，以及哪些区间未计入。
- **能量观测的起止电量**：取电池模式的首末采样，区别于原供电记录可能包含恢复外电后电量反弹的结束读数。

“完整供电记录”“能量覆盖完整”和“完成容量测试”是三个不同概念。一次从 100% 到 99% 再恢复外电的过程也可以有完整供电起止和完整的观测内覆盖率，仍不表示测过满电容量。跨查询边界的记录保留本条观测范围；页面不将其 Wh 按时长比例分摊成范围能量，也不把不同功率依据的记录汇总为健康指标。

已有历史和旧供电记录保留，升级前未记录的 Wh 不从分钟或日均值回填。新增能量与积分游标在历史事务中一起保存，短重启只在游标、身份与时间连续时续接；降级运行期间缺少的新观测不会在再次升级后补算。

## 为什么暂不显示容量与健康度

现有样机电池倍率来自标称 **43.2 Wh** 与设备 SOC 下降的假设，详见[校准依据](calibration.md#已有证据)。再用该倍率计算的能量反推容量，会重复使用同一个容量假设。设备 SOC 也没有被验证为线性的剩余能量比例，不能将短段 Wh 除以电量下降比例后当作独立容量测量。

绝对容量评估需要独立电池侧电流或功率测量，以及明确且可比较的起止、负载与温度条件。若在 UPS 输出侧测电量，应称为相应工况下的可用输出能量，不能忽略转换损耗后直接作为电芯 SOH。当前项目未确认电池温度字段。

## 升级与回退

已使用 v0.6.0 采集器时，只需更新面板镜像。原采集器、校准文件与功率系数可继续使用。来自更早版本的部署，先按 README 更新采集器以提供完整的校准依据。

能量记录保存在原数据库的附加表中，原供电明细表和已有聚合历史保留。回退 v0.6.0 面板后，旧版继续显示原有记录并保留附加数据；再次升级时会核对续接条件。升级、回退前仍应按[备份说明](architecture.md#备份与维护)保存数据库与校准文件。
