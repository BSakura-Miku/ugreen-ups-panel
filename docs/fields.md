# 协议字段与解释边界

本文件描述当前解码器采用的 **64 字节私有报告 `0x71`**。偏移从 0 开始，包含第 0 字节的报告 ID；`u16(n)` 表示偏移 `n`、`n+1` 的两字节无符号大端整数。这是单台设备的观察与逆向解释，不是厂家发布的协议规范。

## 传输

采集器读取原驱动产生的 usbmon 二进制事件，筛选 USB 设备、中断输入端点 `0x81` 和完成状态 `0` 或 `-2`。状态 `-2` 的接纳依据是已观察到该驱动在取消的完成事件中返回完整、持续更新的报告，不代表任意失败载荷都有效。

载荷必须完整，长度为 64 的倍数，并且每段都以 `0x71` 开始。一次事件包含多份报告时，只采用最后一份，使用完成事件时间；不会为前面的报告编造采样时间。截断、混杂、错误端点和过期事件被排除。

## 当前映射

| 偏移 | 解释及换算 | API 字段 | 证据与限制 |
| --- | --- | --- | --- |
| 7 | `0x26` 外部供电、`0x36` 充电、`0x21` 电池供电 | `mode`、`raw_status` | 三种状态均有实机记录；`0x26` 不表示一定达到 100% |
| 16–17 | `u16(16) / 1000` V | `adapter_input_voltage_v`、`input_voltage` | 断电后衰减、恢复后先行升高，支持适配器输入解释；残压不是市电在线证据 |
| 18–19 | `u16(18) / 1000` V | `ups_output_voltage_v`、`output_voltage` | 在样机上跟随约 19 V 直通和约 12 V 电池输出切换 |
| 20–21 | 原始整数 | `raw_fields.be_u16["20"]` | 回充时不随新增耗电增长，不能当作包含充电的总输入电流 |
| 22–23 | `u16(22) / 1000` V | `battery_voltage` | 与四节电芯电压之和一致性较好 |
| 24–25 | `u16(24) / 1000` A，候选比例 | `current` | 电流测点及比例未独立确认，`current_verified=false` |
| 26、27 | 两个独立原始字节 | `raw_fields.byte_26`、`byte_27` | 不命名为确定的温度 |
| 28 | 原始字节 | `raw_fields.byte_28` | 与负载变化相关，可选交流估算模型的输入；不直接命名为瓦特 |
| 29–30 | 充电模式下 `u16(29) / 1000` A | `battery_charge_current_candidate_a` | 与回充及电量上升共同出现；比例仍未经独立电流表验证 |
| 31–32 | 电池模式下 `u16(31) / 1000` A | `battery_discharge_current_candidate_a` | 在放电阶段明显增大；比例仍未经独立电流表验证 |
| 33–34 | 原始整数 | `raw_fields.be_u16["33"]` | 未确定含义 |
| 35–42 | 四个大端整数分别 `/ 1000` V | `cells` | 四节电芯，按报告顺序排列 |
| 43 | 百分比 | `soc` | 设备报告电量，未验证为严格线性的剩余能量比例 |

`cell_delta_mv = (max(cells) - min(cells)) × 1000`。电芯压差可观察均衡变化，不能单独推导 SOH、可用容量或故障结论。

v0.7.0 的 `cell_balance` 是面板根据连续待机采样生成的参考结果，不是新的设备协议字段。电池供电记录的 `energy` 使用未平滑功率候选与有效电池倍率进行时间积分；它只描述有效观测区间，和设备 SOC 百分比、满电容量不同。详见[电池观察说明](battery-observation.md)。

## 功率与历史指标

| 指标 | 计算 | 含义 |
| --- | --- | --- |
| `dc_power_estimate_w` | `u16(18) × u16(24) / 1000000` | 输出电流假设下的原始功率计算，测点及比例未校准 |
| `battery_charge_power_candidate_w` | 电池组电压 × 充电电流候选 | 电池侧充电功率候选，仅充电模式 |
| `battery_discharge_power_candidate_w` | 电池组电压 × 放电电流候选 | 电池侧放电功率候选，仅电池模式 |
| `ac_input_estimate_w` | 可选经验模型与回充补偿，再做平滑 | 交流输入估算，不是直流输出 |
| `battery_energy_estimate_w` | 可选标称容量基准倍率，再做平滑 | 电池侧估算，不是 NAS 输出 |

校准模型默认关闭，详见[功率校准](calibration.md)。`power_verified`、`current_verified` 与 `battery_current_verified` 保持为 `false`，不能因为启用了经验模型就将其当成经过仪器标定的原始电流。

兼容字段 `power_w` 保留原计算含义；新版历史使用 `dc_power_estimate_w`，不再向旧功率序列追加。新版电压历史使用明确测点的字段，与早期 `input_voltage`/`output_voltage` 序列隔离。`load_percent`、`runtime_sec` 和旧 `charge_current_ma` 不提供有效读数，不应将 `null` 替换为 0。

实时样本包含 `calibration_profile` 和 `calibration_verified=false`；未配置模型时两个经验估算值为 `null`，对应质量为 `not_configured`。历史的 `context` 及 CSV 保存模型和质量元数据，旧记录缺少元数据时保留未知来源身份，不进行追溯赋值。

## 有效性与同步

解码器检查报告长度、ID、电量范围、电池及电芯电压等。未知状态保留与模式无关的电池信息，依赖模式的电压、电流和功率留空。电芯和电池组电压之和差异超过阈值时附带说明。

供电切换时，输入残压、输出电压与状态字不一定在同一报告内同时变化。用于校准的记录应排除切换边界，不能仅凭输入电压非零推断设备仍由市电供电。

NUT 每 30 秒独立只读查询，超过 45 秒标记过期。它是另一条诊断来源，不参与私有字段的算术校准；哨兵值或未验证的标准 HID 字段不能转换为可信续航或告警。
